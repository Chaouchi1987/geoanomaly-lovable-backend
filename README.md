# GeoAnomaly Lovable Backend v0.3.1

FastAPI backend for GeoAnomaly Pro.

Earth Engine authentication modes:
1. EARTHENGINE_CREDENTIALS_JSON: OAuth credentials generated by `earthengine authenticate`.
2. GOOGLE_SERVICE_ACCOUNT_JSON: optional service-account JSON.
3. Application Default Credentials for Google Cloud environments.

OAuth credentials are installed at the standard Earth Engine persistent
credential path inside the Render container before initialization.

Never commit credentials to GitHub.

Required Render variables:
- GOOGLE_CLOUD_PROJECT
- EARTHENGINE_CREDENTIALS_JSON
- CORS_ORIGINS

This version performs real Earth Engine/Sentinel-2 acquisition and statistics.
It intentionally does not fabricate anomaly targets.
